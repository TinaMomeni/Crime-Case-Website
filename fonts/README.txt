Put the B Roya font files in this folder, with these exact names:

  BRoya.ttf         (normal)
  BRoya-Bold.ttf    (bold, optional)

The site uses B Roya for all Persian text.
- If a visitor has B Roya installed on their computer, it is used from there.
- If the files are in this folder, it is used for every visitor.
- If neither, the site shows the Persian text with the font Cairo instead.

Before you publish the site online, check the font's license: many free Persian fonts
are free for personal use but not for putting on a website.
